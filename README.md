# আয় - ব্যয়

আয়-ব্যয়ের হিসাবের অ্যাপ — বাংলা ও ইংরেজি, কারেন্সি শুধু BDT, কোনো বিজ্ঞাপন নেই।

## V3 — জমা খরচের মতো হোম (2026-11-07)

- হোম পুরো নতুন করে জমা খরচের ডিজাইনে: হালকা নীল ব্যালেন্স কার্ড + ব্যয়ের
  ডোনাট, নীল পিরিয়ড ট্যাব, তালা/ড্রপডাউন সহ ৩টা মোট কার্ড, দ্রুত যোগ করুন +
  কার্ড সাজান, মাসিক আয়-ব্যয়ের চার্ট, মাসিক ব্যয়ের ফ্লো চার্ট (লাইন চার্ট),
  আয়/ব্যয়/সঞ্চয়ের ৩টা আলাদা খাত বিশ্লেষণ, বাকি ও ধার (Cash), নাম অনুযায়ী
  খাতা, মাসিক বাজেট, অ্যাকাউন্ট ব্যালেন্স, সাম্প্রতিক লেনদেন
- বটম নেভিগেশন: হোম, বাকি ও ধার, বাজেট ও খাতা, তালিকা ও রিপোর্ট, ভয়েস
  (বাংলা ভয়েস শুনে Add ফর্মের বিবরণে নেয়)
- নাম/খাত আলাদা করে দেখা যায়, খাত যোগ/মোছা যায়, সেকশন লুকানো যায়

## V1-এ যা আছে

- হোম: মোট ব্যালেন্স, পাই চার্ট (আয়/ব্যয়/সঞ্চয়), দৈনিক/সাপ্তাহিক/মাসিক/বার্ষিক ট্যাব,
  মোট আয়/ব্যয়/সঞ্চয়, দ্রুত যোগ করুন (আয়/ব্যয়/সঞ্চয়/ট্রান্সফার), মাসিক ব্যয়ের চার্ট,
  খাত অনুযায়ী বিশ্লেষণ, বাকি ও ধার, সাম্প্রতিক লেনদেন
- আয়/ব্যয় যোগ করার ফর্ম: খাত, পরিমাণ, সংখ্যা কীবোর্ড, অ্যাকাউন্ট, তারিখ, নোট
- বাকি ও ধার: নতুন বাকি/ধার যোগ করা, শোধ চিহ্ন দেওয়া
- বাজেট: মাসিক বাজেট সেট করা, খাত অনুযায়ী প্রগ্রেস
- রিপোর্ট: লেনদেনের তালিকা, সার্চ, ফিল্টার, PDF রিপোর্ট, শেয়ার
- নোট: দ্রুত নোট, জরুরি নোট
- সেটিংস: ভাষা (বাংলা/English), কারেন্সি BDT, থিম, পিন লক, ফিঙ্গারপ্রিন্ট,
  লোকাল ব্যাকআপ, লাইভ সিঙ্কের অবস্থা

## লাইভ সিঙ্ক (২ জন, একই জিমেইল)

V1-এ সিঙ্কের কোড তৈরি আছে, কিন্তু Firebase সেটআপ এখনো বাকি — তাই অ্যাপ
আপাতত অফলাইনে চলে (সব ডেটা ফোনের Room ডেটাবেসে থাকে)। সিঙ্ক চালু করতে:

1. Firebase Console-এ নতুন প্রজেক্ট বানান, package name: `com.aybay.app`
2. Authentication-এ Google Sign-In চালু করুন
3. Cloud Firestore চালু করুন
4. Web API key, Application ID আর OAuth client ID
   `app/src/main/java/com/aybay/app/data/SyncConfig.kt`-এ বসান

তথ্য বসালেই পরের বিল্ড থেকে লাইভ সিঙ্ক চালু হবে — দুজন একই জিমেইলে
লগইন করলে একজনের লেখা আরেকজনের ফোনে দেখা যাবে।
